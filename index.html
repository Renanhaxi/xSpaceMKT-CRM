Gerador & Analisador de Link NFC (Google Meu Negócio)

Monte a URL oficial para gravação em tags NFC NTAG213 para avaliação 5 estrelas direta.

💡 Dica: O Place ID pode ser obtido na ferramenta do Google Place ID Finder ou colando a URL de avaliação do cliente.

Tamanho para gravação no chip NFC (NTAG213): 0 / 144 bytes
📱 Passo a Passo de Gravação no Celular:
  1. Instale o app gratuito NFC Tools (Android ou iOS).
  2. Clique em Escrever (Write) → Adicionar um registro (Add record).
  3. Escolha URL / URI e cole o link copiado acima.
  4. Aproxime a plaquinha com o chip NTAG213 da traseira do smartphone até vibrar e confirmar a escrita!
